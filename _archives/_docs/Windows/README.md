# Windows

Terminal setup notes for Windows. They are archived: the current setup is macOS (see the [root README](../../../README.md)).

- [PowerShell](PowerShell/README.md): a PowerShell profile with PSReadLine key bindings, smart quotes and brackets, and helper functions.
- [Oh My Posh](Oh%20My%20Posh/README.md): prompt theme engine, with the theme `ohmyposhv1-ian.omp.json`.
